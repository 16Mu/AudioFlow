## 一份配置、两个视图

WorkspaceState.Configuration 保存唯一 RouteGraph，CanvasView 只记录显示范围。
全局视图显示全部卡片；应用视图显示所选软件及关联卡片。OwnerAppKey 仅用于
保留相关但尚未连线的卡片，不构成另一份配置。浏览未配置应用以草稿显示。

所有卡片、连线、增益、通道和应用设置共享。切换视图不调用音频启停，
也不重建未变的节点对象。撤销和重做使用同一份历史，导入导出使用完整路由图。
运行、暂停与自动恢复意图统一管理；不存在按视图启用的执行状态。

workspace.json 原子保存配置、视图、所选应用、手动名单和音频能力记录。
旧工作区由 LegacyWorkspace 一次性转换：Mode 映射为 View，WasPaused 映射为
RoutingPaused，两份旧配置合并为 Configuration，并清除已移除的 ListenLocally。
转换前校验，写入前保留 workspace.json.pre-migration 原文件，后续只保存共享格式。
未知字段仍拒绝；设备冲突不覆盖原文件。
编辑合并为 50 ms 更新，通过同一控制锁串行保存和应用；暂停时保存，
恢复时执行最新完整配置。

## 默认播放与应用目录

每个已选择软件拥有独立的默认输出卡片，以 PrimaryOutput 和 OwnerAppKey 标记。
新软件默认选择 Windows 当前输出；ApplicationOutputs.Ensure 将已有主输出连线
转接到独立卡片并保留设备与增益。当前软件卡片在单软件视图隐藏选择框并保护删除。
其键为 windows-default，由当前设备目录解析实际端点；Windows 默认设备变化后，
目录刷新会重新解析。默认路由清除本软件管理的应用输出覆盖，使它跟随系统设备。

默认卡片和连线拒绝删除、重接及接入其他来源；下拉选择只更换所属软件原声设备。
新增播放设备连线不移除默认输出，编译时指定的原声去向优先于连线顺序，其余复制。
未配置应用以软件卡片、默认卡片和连线预览，编辑时一次提交；仅导航不写入路由。
未连线的真实麦克风保持不播放。应用声音输入与自身输出分别处理。

自动目录依据活动或非活动播放会话，以及运行中的已知音频应用记录。
仅运行一个进程或存在窗口不作为音频能力证据。已配置与手动添加的应用保留，
即使没有音频或已关闭；手动选择覆盖自动过滤。排序依次为当前使用音频、
已配置但无声、其他已识别音频应用、其余手动项。
添加窗口使用三列网格、显示名称与常用别名搜索，并支持选择可执行文件。

## 音频路由与音量

单应用多输出采用一个 Windows 原生主输出，其余按进程树捕获后复制。
虚拟麦克风使用实际 render/capture 设备对；接收软件需选择对应录音设备。
物理麦克风作为来源混入。校验拒绝自身回送、应用间反馈闭环和无效端口。

RouteConnection.Volume 是实际连线增益，VirtualChannel.Volume 是共享总线增益。
两端音量行引用同一个连接；同一来源到同一设备的重复路径同步增益并去重。
原生输出调节会话音量，复制链路按其与原生增益之比补偿。
零音量主输出会让位于其他有声去向；增益更新复用现有缓冲，避免重建录音器。
应用新开始播放和原生设备移动后会再次应用设置，处理新会话默认音量重置。

EndpointVolumeBinding 读写 IAudioEndpointVolume 并监听系统通知，实现设备总音量、
静音与卡片双向同步。连线增益属于配置；设备总音量属于 Windows 设置。

## 恢复与退出

修改 Windows 设置之前，将应用三种输出角色、会话音量与静音写入
audio-recovery.json。设备音量和静音首次被声流修改时也保存原值。
保存使用临时文件与原子替换，音频数据不写入恢复记录。

暂停停止转发并还原应用输出及会话设置。恢复原有状态按钮还原声流修改的设备设置，
保留画布配置；托盘也提供此操作。较新的外部音量、静音和输出调整按实际状态保留。
原输出端点已断开时解除失效覆盖，回到 Windows 默认设备。

默认关闭窗口会等待还原后退出。关闭在托盘继续运行需在设置中显式开启。
停止某个捕获组件失败时继续处理其余组件和还原；退出还原失败时保留可操作窗口。
异常退出的恢复记录由再次启动恢复，并在需要时继续重试断开的设备。
Windows 的按应用 AudioPolicy 接口通过真实音频会话解析进程身份。已关闭或无音频会话的
进程不能用于该接口；挂起进程、直接改写注册表和广播通知均不能证明音频服务缓存已还原，
相应试验代码已删除。已关闭应用保留原输出角色及原会话音量/静音，重新播放时串行还原。

退出时仍有待恢复项，会启动同一程序的 --recover-pending 模式。该模式没有窗口、不启动
目标应用、不捕获或转发音频；先等待主进程退出，再处理新出现的真实音频会话与重连设备，
每 250 ms 重试，恢复记录为空即退出。重新打开主窗口会通知助手停止，并取得恢复记录独占锁。
同一数据目录的恢复记录始终只有一个写入者；保存和状态报告均使用临时文件原子替换。
电脑重启或助手终止不会删除恢复记录，再次打开主窗口时继续恢复。当前没有添加系统自启动项。
