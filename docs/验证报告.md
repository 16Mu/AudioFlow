# 声流 AudioFlow v0.02 验证报告

验证日期：2026-11-18（北京时间）。

- Release 构建成功，0 个警告、0 个错误。
- 100 项核心逻辑检查通过。
- 31 项新手引导检查通过，使用真实 WPF 窗口和按钮事件，覆盖介绍、前后导航、直接选择步骤、跳过持久化、再次启动不重复显示、设置重新打开和完成引导。
- 无虚拟驱动的场景可以跳过或直接开始，音频配置和开停状态不因引导改变。
- 默认布局与 860 × 640 窗口下的关键操作可见；实际渲染预览随发布提供。
- 53 项设置检查通过，包括新手引导／驱动入口、实际设备列表、设备数量与文字对比度。
- 下载和官网按钮的真实点击会分发对应官方地址；进入页面不自动打开链接或安装程序。
- 两个官方 ZIP 下载链接于本次验证返回 HTTP 200，内容类型为 application/zip；归档中的安装程序文件名与界面安装入口一致。
- 安装入口分发 Windows runas 管理员授权请求，工作目录为用户选择的完整解压目录；无关文件名被拒绝，取消管理员授权可继续使用。
- 安装验证使用受控的启动分发检查，未实际启动安装器或改动本机驱动。下载入口通过请求核验与按钮分发检查，没有驱动用户浏览器。
- 引导偏好单独持久化；null、损坏 JSON 按未看处理，不影响音频工作区。

本版修改启动引导和设置入口。此前的四路实机音频、134 项 WPF 功能及内存测量记录保留在 [v0.01 验证报告](验证报告-v0.01.md)，本次未重跑这些实机音频测试。

源码中保留 --verify-onboarding 和 --verify-settings 复现入口。报告 JSON 与引导／设置预览保存到执行命令指定的目录。
