## 内存对比

在同一台机器上，6 个合成音源、6 个 Windows 原声输出、12 张卡片、无复制支路；每次启动预热 12 秒，再每 2 秒采样一次，共 15 次，以中位数比较。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 私有内存 | 131.1 MiB | 128.6 MiB |
| 工作集 | 187.3 MiB | 183.6 MiB |

私有内存下降约 1.9%。修改前使用上一份 0.0.3 便携包，修改后使用本次 Release 构建；报告 JSON 记录两个确切执行文件路径。
短时内存变化可能受 JIT、系统缓存和窗口渲染影响，不能据此宣称所有场景或长期运行都有固定百分比的改善。事件订阅复用检查另行验证了预览刷新不继续累积音量行。
