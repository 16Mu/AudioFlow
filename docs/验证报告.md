- 32 项首次引导检查通过，覆盖翻页、跳过、记住选择、从设置重新打开，以及引导期间主窗口不显示。

- 拖到错误位置不会自动连好；完成后可以停止模拟声音、重置或继续到驱动页。

- 驱动页与 README 说明：VB-CABLE 和 Hi-Fi CABLE 单独安装都各有 1 路，两款都装才有 2 路；一路可给多个软件听同样的内容。
