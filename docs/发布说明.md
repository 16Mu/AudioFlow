# 声流 AudioFlow v0.01

Windows 11 x64 节点式音频路由器。公开版本保持 0.01，本次改善内存占用、画布整理与关闭连线的显示，并保留设置窗口和设备容量修复。

- 只有默认原声输出时读取现有音频会话电平，减少额外捕获；复制和混音支路仍按需捕获。
- 预览刷新复用连线与音量行，移除音量行时解除事件订阅；设备音量未变化时避免重复刷新控件。
- 整理画布根据节点类型、声音方向、实际卡片尺寸和端口位置布局，并评估连线交叉、遮挡和间距。
- 关闭输出或录音输入后，连线显示为虚线，曲线中间显示红色 X；重新开启后恢复实线。

- 设置窗口显式应用深色主题，修复派生窗口未继承主题造成的白底及黑字。
- 设置页分别显示实际播放设备、独立虚拟麦克风、占用和空闲，列出所有播放端及配对录音端。
- 四路播放输出验证与两路独立虚拟麦克风验证分别标明，避免将耳机和扬声器算作新增虚拟麦克风。
- 右上角只负责开启／停止声音路由，单软件配置与全局画布分别切换，始终共享同一份配置。
- 开启的连线上有流动方向箭头：无声较暗较慢，有声更亮更快，停止路由后静止；已关闭连线使用虚线和红色 X。
- 默认输出新增“不进行输出”，与“输出到所选设备”开关双向同步；保留上次设备、音量、卡片和连线。
- 录音软件卡片可更改默认录音设备，“不进行输入”与“使用所选录音设备”同步。
- 按软件设置 Windows 录音偏好。关闭录音使用一条空闲、无声音的独立虚拟通道，保持其他软件录音；通道不足时提示并保留原选择。
- 打开、保存、另存为和自动保存当前配置文件，显示文件名与保存状态；重开恢复最后文件和开停状态。
- 配置文件损坏或丢失时保留原文件与本地快照，提示重新打开或另存为。
- 根据已安装驱动的实际设备对动态扩容，不写死虚拟麦克风的编号或路数。
- 显示通道总数、占用、空闲、待验证与未连接；用尽时列出接收软件和混音来源，明确选择是否共享。
- 未识别设备可手动绑定。混音器和待验证设备通过信号及串音测试后才计作独立通道。
- 增加录音偏好恢复记录，停止、退出及恢复助手可还原原录音设备；旧工作区继续兼容。
- 保留逐路增益、软件选择网格、设备音量同步、撤销重做、默认卡片保护与青蓝声波分流图标。

开发验证只使用免费驱动；产品支持用户自行安装的免费或付费扩展驱动。
256 组设备的检查属于模拟设备和逻辑路由验证，不代表本机安装或同时运行了 256 个真实虚拟麦克风。
本机真实验证使用两组独立虚拟录音设备和四路播放输出，验证报告说明具体结果。

使用 MSI 安装，或解压便携 ZIP 后打开 portable/AudioFlow.exe。需要 .NET 10 桌面运行时。
绑定固定设备、独占输入或忽略 Windows 默认设备的软件，可能需要重新开启录音或在软件内选择设备。
音频只在本机处理，不上传或默认保存录音；验证使用合成信号并仅保存统计数据。
自有代码采用 MIT 许可证；第三方依赖与虚拟驱动遵循各自许可。源码 ZIP 不含驱动和语言运行时。
