- 使用说明与界面按钮保持一致。版本显示为 v0.03，安装包数字版本为 0.0.3。

安装版双击安装；免安装版解压全部文件后，打开 portable 文件夹里的 AudioFlow.exe。需要 Windows 11 64 位电脑与微软 .NET 10 桌面组件。

VB-CABLE、Hi-Fi CABLE 仍从官方网站单独下载，在引导和设置中都能找到入口。只调整耳机、扬声器的播放去向，可以先用软件，需要时再安装驱动。

声音和设置留在你的电脑上。声流的自有代码使用 MIT 许可，第三方软件按各自说明使用。测试条件和结果见验证报告。
