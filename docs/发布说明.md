# 声流 AudioFlow v0.0.1

以当前完整功能全新发布 v0.0.1。把软件连到耳机、扬声器或另一款软件，让声音去到你想要的地方。

- 给不同软件选择不同播放设备，也能让同一个软件同时在多个设备播放。
- 把音乐、游戏声和你的讲话一起传给聊天、录音或直播软件；需要不同内容时，可以分别安排。
- 首次引导内有可操作的模拟卡片，亲手选择软件、添加设备、拖线并开启模拟声音。完成后继续，也可以跳过或重新练习。
- 引导和设置都有驱动下载、安装和检查入口。VB-CABLE、Hi-Fi CABLE 单装各有 1 路，两款都装才有 2 路；页面用具体例子解释区别。
- 用“接收声音”“发出声音”“主要播放”等直白文字说明操作。README 提供用途、入门步骤、常见问题和界面图片。
- 支持各条线的音量、静音、撤销、自动保存与打开／另存为。停止或退出后尝试恢复原来的声音设置。

安装版双击安装；免安装版解压全部文件后，打开 portable 文件夹里的 AudioFlow.exe。需要 Windows 11 64 位电脑与微软 .NET 10 桌面组件。

下载附件仅包含源码包、安装版和免安装版。使用说明、测试记录与图片见项目页面。

声音和设置留在你的电脑上。驱动从 VB-Audio 官方单独下载，使用说明与许可见官网。声流的自有代码采用 MIT 许可。
